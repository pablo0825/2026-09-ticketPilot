# 預期幣別與價格核對

活動設定可選 TWD（NT$）或 HKD（HK$）；這是預期值，不會切換 Klook 網站幣別，也不換算匯率。GUI 舊活動缺省為 TWD；CLI 的舊 expectation 缺省在 runPurchase 入口補 TWD，明確的未知值不會回退。CLI 要購買港幣時，在每個 target.expectation 加上 currency: "HKD"；同一活動的各順位必須使用相同幣別。

`src/core/currency.ts` 集中支援幣別、顯示符號、Money 型別與核對規則。GUI 由伺服器注入這份純資料，保留傳統腳本，不開放額外檔案路徑。`src/platforms/klook/money.ts` 解析網站價格；各階段以必填幣別和金額核對，內部不自行預設台幣。

選票、配位單價及總額、預訂摘要單價及總額、付款頁總額皆核對幣別與金額。相同數字但幣別不同仍停止，不當作售罄或換順位。付款頁錯幣發生於聯絡資料提交後，保留結果未知、不重送、不重啟購票的既有邊界。

目前只接受正安全整數及正確千分位，不支援小數（包含 .00）或額外費用。既有無括號票種後綴的裸 `$` 仍解析為 TWD；括號票種和各階段總額不接受裸 `$`。HKD 不會以裸 `$` 通過。

舊台幣活動的設定雜湊及開始請求指紋省略 TWD，維持既有持久化紀錄識別；HKD 會進入指紋。歷史 target 事件缺幣別時按舊台幣顯示，不依現在編輯中的活動幣別改寫歷史。

新增第三種幣若沿用相同符號後接整數的格式，可擴充共用幣別定義與測試；若有小數或不同分隔符，需先設計精確金額表示與解析，不能直接取整數。頁面結構與語系差異則另行觀察、調整對應 reader。

本次僅以本機 fixture、攔截路由與 headless Playwright 驗證。沿用 zh-TW 網址、欄位與 DOM；支援 HK$ 不代表已實站確認香港活動或其他語系，也不更動台灣取票手續費欄位的已觀察標籤。
