# 系統架構與資料流

本文件用時序圖說明 GUI、後端服務、資料檔案與購票子程序之間的資料流。

## 四個欄位代表什麼

| 欄位 | 負責什麼 |
| --- | --- |
| GUI | 讓你設定活動、開始購票和查看進度的畫面 |
| 後端服務 | 接收 GUI 的要求，檢查能不能執行，再安排購票工作 |
| 資料檔案 | 保存活動設定、執行紀錄與占用鎖的硬碟檔案；它不是程序 |
| 購票子程序 | 實際操作購票網站，並把進度和結果回報給後端 |

「占用鎖」是一個檔案，用來防止多個購票流程同時執行。

## 箭頭怎麼讀

| 標示 | 意思 |
| --- | --- |
| HTTP API | GUI 提出要求，後端回覆處理結果 |
| SSE | 後端透過 HTTP 長連線，持續把完整的最新狀態送給 GUI |
| IPC | 後端與購票子程序互傳訊息 |
| 檔案讀寫 | 從硬碟讀取資料，或將資料保存到硬碟 |

## 使用的技術

| 技術 | 用在哪裡 | 用途 |
| --- | --- | --- |
| React | GUI | 建立設定與進度畫面 |
| Node.js | 後端服務、購票子程序 | 執行服務與購票程式 |
| Playwright | 購票子程序 | 操作瀏覽器、讀取網站狀態 |
| Node.js `fork` | 後端服務 | 建立購票子程序及 IPC 通道 |
